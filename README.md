# Portfolio

My personal portfolio website: a static site with an overview page, individual project pages, and a resume.

## Structure

```
index.html   Home page
html/        Project pages (project-two through project-seven, plus a project template)
css/         Stylesheets
js/          Scripts
img/         Images
resume/      Resume
```

## View locally

No build step is needed:

```bash
git clone https://github.com/ray01111989/Portfolio.git
cd Portfolio
open index.html    # macOS; use xdg-open on Linux, or double-click the file
```

## Deploy

The site is static, so it can be hosted anywhere. To use GitHub Pages: **Settings, Pages, Deploy from branch, `main`, `/ (root)`**.
